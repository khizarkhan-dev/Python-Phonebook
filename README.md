# Python Phonebook

This is my first independent Python project. It is a terminal-based phonebook application that runs in the command line.

## Features (Current Version)
- Searches for an existing contact by name.
- Returns the contact's details (Age, Number, Status).
- Displays an error message if the contact is not found.

## Planned Features (Roadmap)
- [ ] Add a new contact (Name and Number)
- [ ] Delete a contact
- [ ] View all contacts in the phonebook

## Built With
- Python 3
